# Contribution policy

Nexora is proprietary, source-available software. This repository is published for viewing and evaluation only.

External contributions are not accepted. Do not submit pull requests, patches, feature requests, or security reports through public issues or discussions.

No permission is granted to use, copy, modify, distribute, deploy, or create derivative works from the code or related materials. Any use requires prior written authorization from the Nexora project owner. See [LICENSE](LICENSE) for the complete terms.

Security concerns must be reported through a private channel agreed with the project owner. Do not include vulnerability details in public GitHub issues.
